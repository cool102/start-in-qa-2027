# Вход в тестирование ПО в России

Некоммерческий навигатор с прямыми ссылками для тех, кто хочет стать тестировщиком без опыта: вакансии, стажировки, бесплатные школы работодателей, подработка, каналы с вакансиями и план обучения.

У каждой записи указаны статус и дата проверки: статус верен на эту дату.

## Файлы

| Файл | Что это |
|---|---|
| `data/openings.csv` | Раздел «Куда подаваться». Колонка `kind`: `вакансия`, `стажировка`, `школа` или `подработка` |
| `data/sources.csv` | Каналы и площадки для поиска вакансий |
| `data/resources.csv` | Учебные площадки и примеры портфолио |
| `content/*.md` | Тексты: что учить, план на 90 дней, FAQ, о сайте |

## Как добавить запись (для владельца)

1. Откройте `data/openings.csv` → ✏️.
2. Скопируйте похожую строку в конец и замените значения. Если в тексте есть запятая, возьмите его в "кавычки".
3. Заполните:
   - `kind`;
   - `status`: `открыт`, `закрыт` или `не подтверждён`;
   - `checked`: дата проверки в формате ГГГГ-ММ-ДД;
   - `experience`, `pay`, `skills`: коротко, своими словами, не копируя текст вакансии;
   - `url`: ссылка на первоисточник.
4. Commit changes. Сайт обновится через 1–2 минуты.

## Правила

- Нет рекламы, платных размещений и платных курсов.
- Тексты вакансий не копируются: только краткие условия и ссылка на первоисточник.
- Сайт не собирает данные посетителей.
- Представитель компании или канала может попросить исправить или удалить запись через Issue «Сообщить об ошибке».
