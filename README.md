# Вход в тестирование ПО в России: навигатор

Прямые ссылки на вакансии и стажировки для тестировщиков без опыта, живые площадки и каналы, аудит курсов и план обучения на 90 дней.
У каждой записи есть ссылка на первоисточник, статус и дата проверки.

Данные проверены: **17.09.2026**.

## Что внутри

| Файл | Что это |
|---|---|
| `data/vacancies.csv` | Вакансии и стажировки без опыта: название, компания, город, зарплата, ссылка |
| `data/employers.csv` | Стажировки и школы работодателей |
| `data/sources.csv` | hh.ru по городам, агрегаторы, Telegram-каналы |
| `data/courses.csv` | Курсы: цена, гарантии, условия |
| `data/resources.csv` | Учебные площадки для практики и примеры портфолио |
| `content/*.md` | Тексты: главное, что учить, план на 90 дней, FAQ, ограничения |

## Как предложить запись

Откройте **Issues → New issue → «Предложить стажировку, вакансию или канал»**. Владелец проверит заявку и добавит запись.

## Правила

- Сайт публикует только название вакансии, компанию, город, зарплату и ссылку на первоисточник. Тексты вакансий не копируются.
- Нет рекламы и партнёрских ссылок.
- Сайт не собирает данные посетителей: нет счётчиков, форм и сторонних скриптов.
- Если вы представитель компании или канала и хотите исправить или убрать запись, создайте Issue «Сообщить об ошибке». Запись будет исправлена или удалена.
