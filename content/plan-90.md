# План первых 90 дней

Нагрузка — **10–15 часов в неделю** (вечера и выходные). Если у вас 30+ часов, сожмите план вдвое.
Каждая неделя заканчивается **артефактом в GitHub**: работодатель видит результат, а не слова «изучал».

## Недели 1–3: фундамент

| Неделя | Что делать | Где | Результат недели |
|---|---|---|---|
| **1** | Теория: виды и уровни тестирования, SDLC/STLC, жизненный цикл бага. Тест-дизайн: классы эквивалентности, граничные значения. **Открыть 20 вакансий** из раздела «Куда подаваться» и выписать повторяющиеся требования | бесплатные материалы по основам + раздел «Куда подаваться» | Файл `vacancy-analysis.md` в GitHub: какие требования повторяются |
| **2** | Чек-листы и тест-кейсы. Экспериментальное (исследовательское) тестирование | [saucedemo.com](https://www.saucedemo.com/) (пользователь `problem_user` специально с багами) | 1 чек-лист, 15–20 тест-кейсов, 5 баг-репортов |
| **3** | Клиент-сервер, HTTP (методы, коды, заголовки), DevTools: Network, Console, cookies | [httpbin.org](https://httpbin.org/) + DevTools на saucedemo | Файл `devtools-investigation.md`: 3 запроса со скриншотами и объяснением. **Черновик резюме** |

## Недели 4–6: SQL, API и первые отклики

| Неделя | Что делать | Где | Результат |
|---|---|---|---|
| **4** | SQL: SELECT, WHERE, ORDER BY, JOIN | [sql-academy.org](https://sql-academy.org/en) или [Stepik 63054](https://stepik.org/course/63054/promo) | 30 решённых задач; файл `sql/queries.sql` |
| **4** | **Первые отклики**: краудтестинг (Яндекс Крауд, Crowdtesting.ru) и стажировки со статусом «открыт» (проверьте дату) | раздел «Куда подаваться» | 5 откликов; подписка на 3 живых Telegram-канала |
| **5** | API: REST, JSON, Postman. CRUD-запросы, проверки в Tests | [petstore.swagger.io](https://petstore.swagger.io/), [jsonplaceholder](https://jsonplaceholder.typicode.com/) | Postman-коллекция с 10+ проверками в репозитории |
| **6** | Git (clone, commit, push, branch), оформление README. Jira: завести баги из недели 2 | GitHub | Проект 1 в GitHub: тест-план, чек-лист, тест-кейсы, баг-репорты и DevTools-разбор по saucedemo |
| **6** | Отклики: **10 в неделю**, у каждого 2–3 фразы, почему подходите именно под эти требования | hh.ru по городу + удалёнка, Хабр Карьера, TG | Таблица откликов: дата, компания, ссылка, статус |

## Недели 7–9: проекты и собеседования

| Неделя | Что делать | Результат |
|---|---|---|
| **7** | Проект 2: Postman-коллекция с проверками для petstore.swagger.io + README. Повторить SQL: GROUP BY, HAVING, подзапросы | Второй репозиторий |
| **8** | Проект 3: исследовательское тестирование open-source продукта (если нашли баг — issue по правилам репозитория) + 15–20 SQL-запросов проверки данных на своей локальной базе. Мок-собеседования по вопросам с [youngjunior.ru/qa/interviews](https://youngjunior.ru/qa/interviews) | Реальный issue в open-source проекте (если нашли баг) |
| **9** | Разбор отказов: какие требования повторялись в вакансиях без ответа — подтяните именно их | Обновлённое резюме v2 |

## Недели 10–13: развилка

- **Цель — ручной QA / стажировка manual.** Mobile-тестирование (Android Studio emulator, adb logcat), Linux-команды, ИИ-инструменты для генерации тест-кейсов (с ручной проверкой результата). Отклики 10–15 в неделю.
- **Цель — стажировка AQA.** Один язык под выбранную программу (Java / Python / TypeScript). 5 автотестов на Playwright или Selenium для проекта 1, запуск в GitHub Actions. Подача в школы Aston / Bell Integrator / Перфоманс Лаб или на стажировки МТС, Сбера, Ozon Банка.

## Контрольные точки

| День | Критерий «готов» | Если нет |
|---|---|---|
| 21 | Можете объяснить тест-дизайн на примере, есть 5 баг-репортов | Не переходите к SQL, повторите неделю 2 |
| 42 | 3 артефакта в GitHub, 20+ откликов отправлено | Смените каналы: меньше hh «без опыта», больше стажировок и удалёнки |
| 63 | Было хотя бы 1 тестовое задание или интервью | Попросите знакомого тестировщика посмотреть резюме, сверьте его с требованиями вакансий |
| 90 | Оффер, стажировка или краудтестинг с реальными баг-репортами | Переходите в маршрут «через школу работодателя» |

## Маршруты

**Самостоятельный бесплатный.** План выше + бесплатные тренажёры. Плюс: 0 ₽. Минус: нет внешней проверки. Компенсируйте краудтестингом и open-source issue.

**Через бесплатную школу работодателя.** Выберите 2–3 школы со статусом «открыт» в разделе «Куда подаваться» → «Школы» (например, Aston, Bell Integrator, Перфоманс Лаб) и подготовьтесь к их вступительным требованиям: для Aston и Bell нужны основы Java, для Перфоманс Лаб — Java или Python. Недели 1–6 те же, затем 4 недели основ языка.

**Для студента.** Вам доступны программы «только для студентов»: Т-Академия, Т1, Сбер, МТС, ПСБ, Контур, Р-Вижн, РТЛабс и другие. Когда обычно наборы (по данным на 17.09.2026, проверяйте на сайтах): Контур — отбор в декабре; Касперский SafeBoard — март; Naumen — до 15 мая; YADRO Импульс — весна; Авито — до конца августа; Т-Академия QA Mobile — до конца июля.

**Для взрослого, меняющего профессию.** Студенческие программы закрыты. Фокус: бесплатные школы работодателей (Aston, Bell Integrator требуют высшее или СПО), вакансии «без опыта» с проверкой обязанностей, краудтестинг как первая строка опыта в резюме. Предметный опыт тоже продаётся: бухгалтер → тестирование 1С (Bellerage, Синтегро), связист → НОРСИ-ТРАНС, финансист → банковские проекты.
