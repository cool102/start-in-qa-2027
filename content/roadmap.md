# Что учить

Список составлен по требованиям вакансий и стажировок без опыта (моя проверка от 17.09.2026).

## 1. Обязательно до первого отклика (≈4–6 недель)

| Навык | Как проверить, что освоили |
|---|---|
| Теория тестирования: виды, уровни, SDLC/STLC, жизненный цикл бага | Объясняете разницу между smoke, регресс и ретестом на примере интернет-магазина |
| SQL (SELECT, WHERE, JOIN, GROUP BY) | Решаете 30 задач на [sql-academy.org](https://sql-academy.org/en) без подсказок |
| Тест-кейсы | 20 тест-кейсов на корзину [saucedemo.com](https://www.saucedemo.com/) лежат в GitHub |
| API: что это, REST, методы, коды ответов | Проходите CRUD в Postman на [petstore.swagger.io](https://petstore.swagger.io/) |
| Jira / YouTrack / Test IT / TMS | Умеете завести баг с приоритетом и severity (подойдёт бесплатный аккаунт Jira) |
| Тест-дизайн: классы эквивалентности, граничные значения, таблица решений, pairwise | Для поля «возраст 18–65» выписываете проверки и объясняете каждую |
| Баг-репорты | 5 баг-репортов с шагами, ожидаемым и фактическим результатом, окружением, скриншотом |
| Тестовая документация (тест-план, отчёт) | Тест-план на одну страницу для учебного проекта |
| Postman / Insomnia | Коллекция с проверками (status code, поле в JSON) экспортирована в репозиторий |
| Чек-листы | Чек-лист на форму логина |
| Клиент-серверная архитектура, HTTP | Рисуете путь запроса «браузер → сервер → БД» и показываете его в DevTools |
| DevTools (Network, Console, cookies) | Находите в Network упавший запрос и копируете его как cURL |

## 2. Параллельно с поиском работы

| Навык | Зачем |
|---|---|
| Git и GitHub | Без Git не покажешь портфолио, и Git часто есть в требованиях |
| Мобильное тестирование (Android/iOS) | Геймдев и мобильные продукты чаще берут без опыта |
| Linux / bash | Доктор Веб, МОБИ.Деньги, СТЦ, Т1 |
| ИИ-инструменты (Cursor, Claude, Copilot, генерация тест-кейсов) | Новое требование 2026 года: Fora Soft, Билайн, МТС, Сбер |
| Charles / Wireshark / снифферы | VK, СТЦ, Ренью |
| JSON / XML | Нужны для API-тестирования |
| Английский | Нужен не везде; например, Fora Soft требует B2+ |
| Основы любого языка программирования | Нужны для стажировок по автоматизации и школ работодателей (Aston, Bell, Перфоманс Лаб) |
