# Что учить

Доля — сколько из 47 проверенных вакансий и стажировок без опыта (17.09.2026) упоминают навык в требованиях.

## 1. Обязательно до первого отклика (≈4–6 недель)

| Навык | Доля в выборке | Как проверить, что освоили |
|---|---|---|
| Теория тестирования: виды, уровни, SDLC/STLC, жизненный цикл бага | 57% | Объясняете разницу между smoke, регресс и ретестом на примере интернет-магазина |
| SQL (SELECT, WHERE, JOIN, GROUP BY) | 40% | Решаете 30 задач на [sql-academy.org](https://sql-academy.org/en) без подсказок |
| Тест-кейсы | 34% | 20 тест-кейсов на корзину [saucedemo.com](https://www.saucedemo.com/) лежат в GitHub |
| API: что это, REST, методы, коды ответов | 32% / 28% | Проходите CRUD в Postman на [petstore.swagger.io](https://petstore.swagger.io/) |
| Jira / YouTrack / Test IT / TMS | 28% | Умеете завести баг с приоритетом и severity (подойдёт бесплатный аккаунт Jira) |
| Тест-дизайн: классы эквивалентности, граничные значения, таблица решений, pairwise | 26% | Для поля «возраст 18–65» выписываете проверки и объясняете каждую |
| Баг-репорты | 26% | 5 баг-репортов с шагами, ожидаемым и фактическим результатом, окружением, скриншотом |
| Тестовая документация (тест-план, отчёт) | 26% | Тест-план на одну страницу для учебного проекта |
| Postman / Insomnia | 21% | Коллекция с проверками (status code, поле в JSON) экспортирована в репозиторий |
| Чек-листы | 19% | Чек-лист на форму логина |
| Клиент-серверная архитектура, HTTP | 17% / 15% | Рисуете путь запроса «браузер → сервер → БД» и показываете его в DevTools |
| DevTools (Network, Console, cookies) | 13% | Находите в Network упавший запрос и копируете его как cURL |

## 2. Параллельно с поиском работы

| Навык | Доля | Зачем |
|---|---|---|
| Git и GitHub | 19% | Портфолио без Git не покажешь, а знание Git ещё и прямое требование |
| Мобильное тестирование (Android/iOS) | 11% | Геймдев и мобильные продукты чаще берут без опыта |
| Linux / bash | 13% | Доктор Веб, МОБИ.Деньги, СТЦ, Т1 |
| ИИ-инструменты (Cursor, Claude, Copilot, генерация тест-кейсов) | 11% | Новое требование 2026 года: Fora Soft, Билайн, МТС, Сбер |
| Charles / Wireshark / снифферы | 9% | VK, СТЦ, Ренью |
| JSON / XML | 6% | Нужны для API-тестирования, отдельно упоминаются редко |
| Английский | 6% | Fora Soft требует B2+, большинство не требует |
| Основы любого языка программирования | 36% | Встречается в стажировках по автоматизации и в школах работодателей (Aston, Bell, Перфоманс Лаб) |
